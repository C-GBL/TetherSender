# Tether Sender

Windows companion app for **Tether Audio**. It sends your PC's audio to your iPhone over the USB cable.

## Requirements

- Windows 10/11 (x64)
- [Apple Devices](https://apps.microsoft.com/detail/9np83lwlpz9k) app or iTunes installed
- Tether Audio open on the iPhone, plugged in and trusted

## Install

Download the latest zip from [Releases](https://github.com/C-GBL/TetherSender/releases), unzip, and run `TetherSender.exe`. It lives in the system tray. Right-click the icon to pick the iPhone and the audio source.

## Build from source

Requires the .NET 8 SDK.

```
dotnet build -c Release
```
